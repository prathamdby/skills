# Verify

Pick the best of N attempts at the same task. N comes from the user, with 3 as the default. Never invent it.

Run each attempt in its own worktree or copy so the attempts never touch each other's files. A branch on the same tree does not count as separate. You judge, you do not compete. Never write one of the attempts yourself. If you cannot run attempts in parallel, run them one at a time.

Write down two to four things a good attempt must do before you look at any of them. Then compare the attempts in pairs, one thing at a time, and swap the order so position does not bias you. Trust what you can run and observe, not what an attempt says about itself. Never collapse the comparison into a single score out of ten.

Rank the attempts from the pairwise results and report the winner with the reasons. When every attempt fails, say so instead of picking a least-bad one.
