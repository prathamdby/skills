# Interactive and management syntax

For a requested TUI run `cursor-agent "<prompt>"` in the workspace, omitting
prompt for an empty session. The user owns dialogs. Do not automate clicks
through trust/permissions; apply `trust-integrations.md` on refusal.

For other requested commands, use their scoped help to construct argv.
Apply the named login/MCP/plugin/worker/Bedrock contract in
`trust-integrations.md` before changing state. Discovery does not grant trust,
force, MCP approval, desktop sharing, or credential access.
Done when the authorized command result or intended live TUI is verified.
