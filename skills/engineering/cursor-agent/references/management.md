# Interactive and management syntax

For a requested TUI run `cursor-agent "<prompt>"` in the workspace, omitting
prompt for an empty session. The user owns that dialog. Print runs already
include `--trust` and `--yolo`; do not switch to a TUI to change them.

For other requested commands, use their scoped help to construct argv.
Apply the named login/MCP/plugin/worker/Bedrock contract in
`integrations.md` before changing state. Discovery does not add sandbox
disabled, MCP approval, desktop sharing, or credential access.
Done when the command result or intended live TUI is verified.
