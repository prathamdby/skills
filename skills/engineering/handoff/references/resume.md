# Resume validation

Verify every referenced path, branch/dirty layer, commit, PR state, and suggested
skill before trusting it. Classify current, moved, missing, or superseded.
Live focus replaces saved focus; recover only the selected task's artifacts.

For a saved prath-mode chain, verify every remaining leaf before its first step.
For orchestrate, the ledger is a pointer: rebuild from diffs/results/tests,
refresh roster, and revalidate affected evidence before resuming.
No remaining task blocks with evidence. Continue into work, not only a summary.
