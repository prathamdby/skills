# Always-on probes

Score every probe in each active section. A hit changes a surface, breaks a
guarantee/invariant, or widens load; turn it into a cited risk and owned step.

## Contracts/API

Endpoints, signatures, removed fields, error shapes, contract versioning,
call-site migration, mocks/fixtures, generated-client staleness, undocumented
caller reliance, inherited conventions without evidence, changed outcomes
or failure cases without assertions/manual proof.

## Failure/rollback

Partial writes, retry storms, idempotency keys, timeout budgets, rollback order,
reversibility, feature-flag kill path, data repair, alert thresholds during
migration, on-call burden.

## Longevity/debt

Duplication, TODO density, recent reverts, outgrown abstractions, widened test
gaps, rotting docs, reversibility cost, deletion plan, duplicated implementation
in the plan, milestones too large to review before expansion.

Conditional probes now live under `references/`; activate them using `SKILL.md`.
