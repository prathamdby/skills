# Trace and logs

GH_TRACE=1 prints counts and path/query names only. Never log tokens,
Authorization, or signed URLs.
Download jobs/id/logs through gh API; do not forward a GitHub bearer header
to the redirected blob-storage URL. PK indicates ZIP: unzip, retain a failed
step snippet, remove the ZIP.

Existing scripts use a 0700 temporary gh-ci directory and 0600 files.
Cite printed paths instead of pasting full logs.
