# Check an approved milestone

Take the first open milestone not deferred/skipped. For legacy documents
without expected outcomes, derive them only from approved Success and milestone
text. If ambiguous, name the gap, leave it open, return `AWAITING_USER`.

Show each exact command and run only after its approval. Record assertion or
observed manual proof for each expected success/failure result. Compare promised
symbol names and signatures. Tick only when every box passes, symbols match,
and every approved outcome is proved. Otherwise record promised X; landed Y;
reason. Product files are not edited by checking.

Report milestone; automated command/expected/evidence/pass or fail/exit;
manual step/expected/observed/confirmed or unconfirmed; symbols landed/missing/
changed; outcomes proved/missing/contradicted; result ticked/awaiting manual/
awaiting outcome/deviation; next open milestone; deferred symbols.

Done with CHECKED for a ticked milestone or all complete; otherwise AWAITING_USER.
